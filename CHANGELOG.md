# Changelog

All notable changes to Panorama are documented here.

Panorama follows SemVer (`Major.Minor.Patch`) in release notes. The ProcessWire module version uses the numeric equivalent, so `1.0.0` is published as `100`.

## [1.0.0] - 2026-06-20

### Added

- Initial public release.
- Dashboard with media totals, field breakdown, file type breakdown, top pages/templates, largest files and recent uploads.
- Explorer workspace with gallery, page and template views.
- Duplicate finder with background scanning, visual cards, search and drawer details.
- Audit tab for images missing descriptions.
- Cleanup tab for broken references, orphaned originals and orphaned variations.
- Warmup tab for background image variation generation.
- Background loading for thumbnail-heavy dashboard panels.
- Shared media cards across dashboard, explorer, duplicates and audit views.
- ProcessWire i18n support for PHP and JavaScript interface labels.
- Support for custom ProcessWire field icons in dashboard field rows.
- Compatibility with ProcessWire 3.0.227+ and PHP 8.3+.
